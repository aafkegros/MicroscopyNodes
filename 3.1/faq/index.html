    Troubleshooting, help, and contact

    My volume is not visible

    Microscopy volumes are not shown in Solid mode. Switch the viewport to Material Preview or Rendered Preview.

    For a scattering volume, also make sure the world is not black or add a Blender light. See Adjust color, contrast, and opacity.

    My OME-Zarr metadata does not load

    Copy the direct .zarr address into the field rather than using the file browser. Collections, wells, fields, and label groups may require a path to the specific image array. See OME-Zarr troubleshooting.

    Blender becomes slow with my data

    Begin with the smallest useful multiscale level, reduce visible channels, and work at low render samples. Reload the complete data or only a masked region at higher resolution for final output. See Large datasets and sparse reloading.

    Where should I change something?

    • Use Geometry Nodes for masks, geometry, projection, and data processing.
    • Use Shader Nodes for color, opacity, and lighting.
    • Use the loading panel to change scale, time range, storage, or channel representation.

    The workflow overview explains this separation.

    Ask for help

    The main venue for Usage questions is the image.sc forum and you can also search here for previous questions.

    If you've found a bug (or suspect something even a little bit of being non-intended behaviour), don't be afraid to open an issue!
