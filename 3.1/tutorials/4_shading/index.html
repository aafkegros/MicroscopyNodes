    Shading

    For a guided first adjustment, start with Adjust color, contrast, and opacity. This section is the detailed reference for the generated shader trees.

    Shading encompasses the visualization of Blender's objects. The shading options can be found in two places:

    • in the Shader Nodes workspace, find this in the topbar.
    • in the material tab of the properties.

    These two locations contain the same information, laid out in different ways.

    The default Microscopy Nodes shaders are built from nodes and describe how the loaded objects interact with light, color, and transparency.
